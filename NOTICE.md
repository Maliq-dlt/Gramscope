# Lisensi dan atribusi

[MIT](LICENSE) berlaku untuk source asli proyek yang haknya dimiliki kontributor.
Lisensi ini tidak mengganti lisensi library, model, corpus, dataset, atau aset pihak
ketiga. Distribusi aplikasi gabungan harus memenuhi ketentuan komponennya.

| Komponen | Ketentuan |
| --- | --- |
| Ultralytics/YOLO | AGPL-3.0 atau lisensi enterprise yang berlaku; MIT pada source asli tidak menghapus kewajiban AGPL aplikasi gabungan |
| Qwen3-1.7B | Apache-2.0 sesuai model card/revision |
| Model helm keremberke | Model card belum menyatakan lisensi bobot eksplisit; verifikasi sebelum redistribusi/komersialisasi |
| HeroUI styles | Metadata MIT, LICENSE bawaan Apache-2.0; perbedaan dicatat, belum terselesaikan |
| Tailwind | MIT; atribusi asli disimpan |
| Wikipedia Indonesia pilot | CC BY-SA 4.0; URL/history/revision/rightsinfo/hash disimpan importer, extract tidak dibundel; lihat [sumber data akademik](extensions/reports/DATA_SOURCES.md) |
| Wikipedia Indonesia full snapshot | Wikimedia/HF 20231101.id menyatakan CC-BY-SA-3.0/GFDL; URL artikel dan response hash tersedia pada [manifest](extensions/results/academic_upgrade_v2/source_manifest/idwiki.json), full text tidak didistribusikan |
| KenLM / Boost | KenLM source LGPL-2.1, Boost Software License 1.0; tool validasi lokal, bukan dependency runtime atau bobot |

| TrackEval 1.3.0 maintained fork | MIT, kovalp/TrackEval; dependency evaluasi developer |
| Brown/Reuters dan footage publik | Ketentuan sumber masing-masing, bukan MIT source proyek |
